CASA CUBO — INICIO / VERSIÓN EDITORIAL
=========================================

Esta versión reproduce la última propuesta visual generada para Casa Cubo:
- composición editorial y asimétrica
- tipografía Space Grotesk + DM Sans
- paleta crema / rosa / verde / amarillo
- fotografías grandes y tarjetas
- navegación responsive
- tienda separada en Empretienda

ARCHIVOS
--------
index.html
css/styles.css
js/script.js
assets/img/  -> imágenes locales
assets/mockup-referencia.jpg -> referencia visual

IMPORTANTE SOBRE LAS IMÁGENES
-----------------------------
Las imágenes incluidas son recortes de la maqueta visual generada para que el proyecto
funcione inmediatamente sin depender de enlaces externos. Son material de prototipo.
Cuando tengas fotografías reales de Casa Cubo, reemplazá los JPG de assets/img/ conservando
los mismos nombres, o modificá las rutas en index.html.

EMPRETIENDA
-----------
En index.html el enlace está configurado como:
https://casacubo.empretienda.com.ar/

Si tu URL definitiva es otra, buscá esa dirección y reemplazala.

EDITAR CONTENIDO
----------------
Los textos principales están directamente en index.html para que puedan editarse fácilmente
en Dreamweaver o VS Code.

Esta estructura también está preparada para una futura integración con un CMS: las secciones
de hero, categorías, talleres, nosotros y galería están separadas y tienen campos claramente
identificables.

ABRIR
-----
Abrí index.html directamente en el navegador o usá Live Server en VS Code.

NO HAY FRAMEWORKS
-----------------
El sitio usa HTML + CSS + JavaScript puro. No requiere instalación de Node ni dependencias.
