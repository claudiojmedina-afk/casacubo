# Casa Cubo — Homepage + Landing Pages Administrables

Sistema integrado:
- Homepage editorial de Casa Cubo.
- Agenda `/eventos/`.
- Landing individual por evento.
- Administrador Decap CMS en `/admin/`.
- Cada evento incluye URL de Google Forms; las respuestas quedan en la hoja de cálculo vinculada a ese formulario.
- Los eventos publicados aparecen automáticamente en la sección de talleres/eventos de la homepage.

## Desarrollo
npm install
npm run dev

## Producción
npm run build

La salida se genera en `_site/`.

## CMS
Configurar el repositorio y Git Gateway/Netlify según el hosting elegido.
